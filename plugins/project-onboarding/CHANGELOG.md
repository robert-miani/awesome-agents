# Changelog — project-onboarding

## [0.1.0] — 2026-06-16

### Added
- Initial release
- `repository-knowledge` — generates a focused knowledge pack from repository code, configuration, and external context sources (Jira, Confluence)
- `docx-to-md` — converts Word documents to Markdown for use in agent workflows
- `common-ascii-diagram` — generates ASCII architecture and flow diagrams
- `common-mermaid-diagram` — generates Mermaid diagrams (sequence, flowchart, ER)
- `common-plantuml-diagram` — generates PlantUML diagrams
- `git-commit` — standardised git commit workflow
