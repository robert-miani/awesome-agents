# Changelog — implementation-dotnet

## [0.1.0] — 2026-06-16

### Added
- Initial release
- `dotnet-architecture` — documents the overall .NET solution architecture
- `dotnet-architecture-infrastructure-db` — database and infrastructure layer conventions
- `dotnet-architecture-presentation-rest` — REST API presentation layer conventions
- `common-hexagonal-architecture` — hexagonal (ports and adapters) architecture patterns
- `dotnet-scaffold` — scaffolds a new .NET feature module following clean architecture conventions
- `dotnet-feature` — implements a complete feature (command, handler, entity, repository)
- `dotnet-module-registration` — registers modules and dependencies in the DI container
- `dotnet-mediatr` — implements MediatR commands, queries, and pipeline behaviours
- `dotnet-ef-core` — implements EF Core entities, configurations, migrations, and repositories
- `dotnet-fluent-validation` — implements FluentValidation validators for commands and requests
- `dotnet-error-handling` — implements global error handling and problem details responses
- `dotnet-configuration` — manages strongly-typed configuration and options patterns
- `dotnet-api-versioning` — implements API versioning strategies
- `dotnet-infrastructure-http` — implements typed HTTP clients and external service integrations
- `dotnet-code-style` — enforces .NET code style and naming conventions
- `common-clean-code` — applies clean code principles across the codebase
- `git-commit` — standardised git commit workflow
