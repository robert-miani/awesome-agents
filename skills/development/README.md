## React (feature-based)

| Skill | Description | Recommended for |
|-------|-------------|-----------------|
| [react-architecture](react-architecture/README.md) | `features/` + `shared/` layout, dependency rules, app shell | New apps, refactors, "where does this go?" |
| [react-code-style](react-code-style/README.md) | Naming, imports, components, hooks, forms | All React code generation and review |
| [react-typescript](react-typescript/README.md) | Strict TS, Zod, unions, API typing | Typing and validation |
| [react-configuration](react-configuration/README.md) | Vite env, `appConfig`, Zod env schema | Config and feature flags |
| [react-api-client](react-api-client/README.md) | axios clients, interceptors, auth, ApiError | HTTP layer setup |
| [react-data-fetching](react-data-fetching/README.md) | TanStack Query keys, hooks, mutations, invalidation | Server state in features |
| [react-unit-testing](react-unit-testing/README.md) | Vitest, Testing Library, mocks, coverage; `tests/` mirrors `src/` | Component, hook, and util tests |
| [react-scaffold](react-scaffold/README.md) | Greenfield app bootstrap; reference React template tooling + features/shared | New React projects |
| [react-feature](react-feature/README.md) | End-to-end feature: types, API, hooks, pages, routes, tests | New screens and workflows |

Load **`react-architecture`** and **`react-code-style`** first for new React work.
